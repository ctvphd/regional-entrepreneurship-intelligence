## Consistency audit

- **Entrepreneurial alignment gap:** meaningful shortfall from a model-based expectation first; formal construct second.
- **p20 residual threshold:** lowest 20% of training-period differences first; technical label second.
- **Temporal holdout:** later years never used for training first; technical label retained in notes and backup material.
- **Average Precision:** ranking quality for the less-common gap outcome first; AP and value second.
- **ROC-AUC:** higher-risk versus lower-risk separation first; technical name and value second.
- **Brier score:** probability error first; technical name and value second.
- **MSA-cluster bootstrap:** repeated resampling that keeps each metro together first; technical name second.
- **Sector-only benchmark:** what industry identity alone can predict first; benchmark name and AP second.
- **Precision / recall / lift:** review yield, share of all gaps captured, and concentration first; technical labels second.
- **False positive:** additional review that did not become a realized gap; never described as worthless.
- **Model abstention:** insufficient information for a reliable score; never treated as a negative prediction.
- **Benchmark-relative shift:** more cases below expectation while raw startup activity increased; not a simple decline.

## Boundary audit

The main deck does not describe the score as a regulatory classification, funding eligibility criterion, distress certification, causal diagnosis, guaranteed prediction, current forecast, or automatic intervention rule.
